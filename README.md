# 易创写作 · iPad 本地创作版

一个 **iPad 触屏优化、纯本地、离线可用** 的网文写作 Web 应用（PWA），复刻了 GitHub 开源项目
[`easy-writing`（易创）](https://github.com/yilujian/easy-writing) 的核心写作体验，
并加入 **AI 辅助（BYOK，自备 API Key）**。

- **纯本地**：作品、章节、大纲/角色/设定/时间线、灵感、码字记录全部存在设备本机（IndexedDB + localStorage），无需注册登录。
- **离线可用**：安装为 PWA 后，断网也能写、自动保存、留历史版本。
- **稿子攥在自己手里**：随时整本导出 TXT / JSON（含参考资料），随时备份。

> 说明：本版本是基于 easy-writing 的产品思路独立实现的前端项目，未使用其源码；榜单爬虫等
> 依赖桌面系统能力的功能在 iPad 浏览器里无法实现，故未包含。

## 功能

### 书架
- 多作品管理、分组、封面（颜色 / Emoji / 自定义图片）、回收站（可恢复/彻底删除）
- 整本 TXT/JSON 导入导出、全量备份、JSON 迁移

### 写作
- 富文本编辑器（加粗/斜体/下划线/删除线/标题/引用/列表/对齐）
- 卷 / 章目录树：多卷、多章，上移/下移、重命名卷、删除
- 边写边存（500ms 自动落盘 + 关窗/切后台自动保存）
- 每章自动保留历史版本（最多 30 份），可预览/恢复
- 全书查找替换、敏感词检测（本地词库可自定义）
- 多套打字音效（清脆/青轴/茶轴/打字机/气泡，可静音）
- 专注模式（全屏沉浸）、自爆挑战（停止输入倒计时）
- 手机阅读预览（与正文实时同步的窄屏预览）
- 编辑器自由排版：字体、字号、行高、文字颜色、正文宽度、段间空行、网格线、写作背景图（内置 + 自定义）

### 参考资料五件套
- 大纲、角色、设定、时间线、故事线（均自动保存）
- 角色关系图：角色节点 + 关系连线画布（拖拽、连线、编辑、删除）
- 故事线思维导图：节点/连线自由画布（拖拽、连线、编辑、删除）

### 码字统计
- 今日手写 / AI 分开记账、累计字数、连续天数、每日目标、近 14 天趋势

### 灵感速记
- 首页快记 + 素材库（同一份数据）

### AI 辅助（BYOK，需自备 API Key）
- 支持 DeepSeek / 通义千问 / Kimi / 智谱 / OpenAI / Ollama 及多数 **OpenAI 兼容**接口
- 划词工具：选中文字一键 润色 / 扩写 / 纠错 / 自定义指令，采纳或废弃
- 续写：流式续写直接进正文，AI 产出单独计入 AI 字数
- 妙笔对话：右栏 AI 顾问（剧情/人设/设定），会话历史本地保存
- 工作流一键建书：灵感 → AI 生成书名/简介/大纲（卷章结构）→ 一键建书 → 逐章自动生文
- 竞品拆书：TXT 整本导入或选现有作品，逐章拆解节奏/爽点/钩子 + 黄金三章深析 + 全书报告
- 取名器、简介生成、调用账本
- 提示词全开放：每个场景的提示词与采样温度都可改、可恢复默认

## 在 iPad 上使用（三步）

PWA 需要 **HTTPS** 才能安装与离线缓存。推荐用免费静态托管，下面任选其一：

### 方式 A：GitHub Pages（推荐，免费）
1. 把本目录推到一个 GitHub 仓库（或直接上传文件）。
2. 仓库 `Settings → Pages → Source` 选 `main` 分支根目录，保存。
3. 等 1 分钟，用 iPad Safari 打开生成的 `https://<用户名>.github.io/<仓库名>/`。
4. 点 Safari 的 **分享 → 添加到主屏幕**，即可像 App 一样全屏使用、离线可写。

### 方式 B：Netlify / Cloudflare Pages / Vercel
把本目录拖到对应平台（Netlify 的 “Drag & drop”），得到 HTTPS 地址后同样“添加到主屏幕”。

### 方式 C：同一局域网临时预览
在电脑上运行（电脑与 iPad 同一 Wi-Fi）：
```bash
python serve.py          # 或 python -m http.server 6789 --bind 0.0.0.0
```
然后用 iPad Safari 打开 `http://<电脑局域网IP>:6789/`。
> 注意：局域网 `http://` 不是 HTTPS，**不能安装为 PWA**，仅适合临时预览。

## AI（BYOK）配置

1. 打开应用 → 右上角 ⚙ 设置旁的 **首页「AI 工具 → 模型」**（或写作台右栏「AI → 模型」）。
2. 选一个预设（如 DeepSeek）自动填充接口地址与模型名，填入你自己的 **API Key** → 保存 → 设为默认。
3. 写作时：选中文字点工具栏「润色/扩写/纠错」，或点「续写」；右栏「AI」里可和顾问对话。

**常见问题**
- 本地模型（Ollama / LM Studio）：API Key 留空；若报 403，给 Ollama 设置
  `OLLAMA_ORIGINS=*` 后重启。
- 若某服务商调用报“跨域 / CORS”错误，说明该服务未开放浏览器直连；请换用支持浏览器
  CORS 的服务（如 DeepSeek、OpenAI），或经支持 CORS 的网关访问。
- “思考型”模型（DeepSeek Reasoner、千问思考版等）输出慢/被截断：模型设置里
  关掉“思考模式”，并把“最大输出 Tokens”调到 32768 以上。

## 数据与备份

- 数据存在浏览器的 IndexedDB / localStorage（每个站点独立）。
- 备份：首页「导入 / 数据 → 导出全部数据」，或单个作品菜单「导出 TXT / 导出 JSON（含参考资料）」。
- 换设备迁移：导出 JSON → 新设备导入 JSON。
- 敏感词词库、每日目标、主题等在 ⚙ 设置里修改。

## 项目结构

```
easy-writing-ipad/
├── index.html            # 入口
├── manifest.webmanifest  # PWA 清单
├── sw.js                 # 离线缓存 Service Worker
├── css/style.css         # 主题与布局
├── js/
│   ├── utils.js          # 工具 / 弹窗 / 字数统计
│   ├── db.js             # IndexedDB + localStorage 存储层
│   ├── stats.js          # 码字统计
│   ├── editor.js         # 富文本编辑器
│   ├── reference.js      # 参考资料五件套
│   ├── export.js         # 导入导出 / 敏感词
│   ├── ai.js             # AI 辅助（BYOK）
│   ├── bookshelf.js      # 书架 + 写作台 UI
│   └── app.js            # 入口
├── icons/                # 图标（scripts/gen_icons.py 生成）
└── scripts/gen_icons.py  # 图标生成脚本（纯标准库）
```

纯 HTML/CSS/JS，无构建步骤、无依赖，直接部署即可。
